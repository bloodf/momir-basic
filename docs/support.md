# Support

Last updated: April 2026

Momir Basic is a Magic: The Gathering card randomizer app with thermal printer support over Bluetooth and BLE.

## Printer Compatibility

Tested compatible printer models:

- MPT-II

Additional printers may work, but compatibility has not yet been confirmed in this document.

## Troubleshooting

### Bluetooth printing issues

Make sure the printer is paired in your device's system Bluetooth settings before trying to print from the app.

### Connectivity issues

If the app cannot connect to the printer, restart both the app and the printer, then try again.

## Before Contacting Support

Please include the following details when possible:

- Device model
- Operating system version
- Printer model
- Whether the printer is already paired in system settings
- A short description of the problem
