# Task 1: Support Contract — Blocked Requirements
# Generated: 2026-03-29
# Plan: thermal-printer-production-hardening

## BLOCKED: Universal ESC/POS Compatibility
### Requirement
"Support any ESC/POS printer"

### Blocker
No hardware proof exists for universal compatibility. The app uses react-native-thermal-pos-printer which supports common ESC/POS printers, but this does NOT guarantee all printers work.

### Required to Unblock
1. Source specific printer models for certification
2. Populate certification matrix with printer models, firmware, paper width
3. Complete physical validation on each matrix entry
4. Document any printer that fails validation

### Status
UNPROVEN — Cannot claim universal compatibility without certification evidence.

---

## BLOCKED: Non-MFi iOS Classic Bluetooth
### Requirement
"Support Classic Bluetooth printers on iOS without MFi certification"

### Blocker
Apple restricts Classic Bluetooth to MFi/External Accessory hardware. The app explicitly filters out Classic on iOS (see registryService.filterTransport).

### Required to Unblock
1. Obtain MFi/External Accessory certified printer hardware
2. Verify printer appears in iOS External Accessory protocol list
3. Test Classic Bluetooth printing on iOS with MFi hardware
4. Document MFi hardware model and certification status

### Status
BLOCKED — MFi hardware required. Without it, iOS Classic is not supported.
