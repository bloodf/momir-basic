Task 2: Remove Fake/Mock Printer Runtime Selection
====================================================

Date: 2026-03-29

SUMMARY
-------
Removed FakePrinterAdapter from all production/runtime selection paths.
Factory now fails explicitly with named error types instead of silently
falling back to fake behavior.

CHANGES MADE
------------

1. expo/services/printer/adapters/factory.ts
   - REMOVED: FakePrinterAdapter import and fallback logic
   - REMOVED: isTest environment check returning fake
   - REMOVED: isWeb platform check returning fake
   - REMOVED: !hasNativeModule check returning fake
   - ADDED: UnsupportedPlatformError ( thrown on web )
   - ADDED: MissingNativeModuleError ( thrown when native module absent )
   - ADDED: UnavailableTransportError ( available for future transport issues )

2. expo/app/(tabs)/settings/printer.tsx
   - REMOVED: usesFakeAdapter useMemo detection
   - REMOVED: webNotice UI block ( lines 571-580 )
   - isWeb variable still declared but no longer used ( stale, harmless )

PRODUCTION BEHAVIOR CHANGE
--------------------------
BEFORE: factory.ts → FakePrinterAdapter on web/test/missing-native
AFTER:  factory.ts → throws UnsupportedPlatformError or MissingNativeModuleError

RUNTIME PATH STATUS
-------------------
[✓] Production iOS device with native module → NativeThermalPrinterAdapter
[✓] Production Android device with native module → NativeThermalPrinterAdapter
[✗] Web platform → UnsupportedPlatformError ( explicit failure )
[✗] Missing native module → MissingNativeModuleError ( explicit failure )
[?] Test environment → Tests must use test-only injection ( see below )

TEST-ONLY INJECTION
-------------------
Tests MUST NOT rely on factory.ts returning FakePrinterAdapter.
Tests should import FakePrinterAdapter directly for test isolation:
  import { FakePrinterAdapter } from '@/services/printer/adapters/fake';

E2E TESTS
---------
e2e/printer-qa.spec.ts is fake-driven and WILL FAIL after this change.
Fake devices ( fake-ble-001, fake-classic-001 ) no longer discoverable.
E2E tests require rewrite to use real printers or test-only entrypoints.
Tasks 8-12 are blocked by this task and must address E2E separately.
