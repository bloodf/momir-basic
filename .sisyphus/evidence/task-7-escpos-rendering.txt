## Capability Validation Flow
1. Document calls `renderer.setCapabilities(capabilities)`
2. Document calls renderer methods (printImage, printQRCode, cutPaper)
3. Renderer checks `requireCapability(feature)` before each operation
4. If capability is false, renderer throws explicit error with capability flag

## Architectural Notes
- `printImage()` expects actual base64-encoded raster bitmap (1-bit dithered format)
- URL-to-raster conversion should happen at a higher layer (outside renderer scope per task)
- Documents must check capabilities before calling renderer OR pass valid data
- DiagnosticsDocument previously had unguarded cutPaper() - fixed
