Implementation:
1. Define `safeJsonParse<T>(json: string | null, fallback: T, storageKey: string): T`:
   - If `json` is null or empty, return `fallback`
   - Try `JSON.parse(json)` and return the result cast as `T`
   - On catch: call `logger.error(ErrorCategory.Storage, 'Corrupted data in AsyncStorage key "{storageKey}", clearing and using defaults', error)`, then `void AsyncStorage.removeItem(storageKey)` (fire-and-forget, does not block return), then return `fallback`
2. Import AsyncStorage from `@react-native-async-storage/async-storage`
3. Import `logger, ErrorCategory` from `@/utils/logger`

Then replace all 5 unprotected JSON.parse calls on AsyncStorage data (per RESEARCH.md Pitfall 6 — do NOT double-wrap route param JSON.parse in card.tsx/print-preview.tsx):

2. `providers/SettingsProvider.tsx` `getPrinterPreferencesFromSettings` (line ~125): Replace `JSON.parse(raw)` with `safeJsonParse(raw, {}, SETTINGS_KEY)`
3. `providers/SettingsProvider.tsx` `savePrinterPreferencesToSettings` (line ~131): Replace `JSON.parse(raw)` with `safeJsonParse(raw, {}, SETTINGS_KEY)`
4. `providers/HistoryProvider.tsx` queryFn (line ~17): Replace `JSON.parse(stored) as Card[]` with `safeJsonParse<Card[]>(stored, [], HISTORY_KEY)`
