# Store Assets Manifest — Momir Basic

## App Store (iOS)

### Required Screenshots
| Device | Size | Quantity | Notes |
|--------|------|----------|-------|
| iPhone 6.5" (required) | 1284x2778 | 1-10 | Use any iPhone 11+ display size |
| iPhone 5.5" (required) | 1242x2208 | 1-10 | Use any iPhone 8 display size |
| iPad Pro 12.9" (required) | 2048x2732 | 1-10 | If iPad is supported |
| iPad Pro 11" (optional) | 1668x2388 | 1-10 | Optional |

### App Preview (optional but recommended)
- Video: Up to 30 seconds showing main app flows

### Required Assets
| Asset | Specification |
|-------|---------------|
| App Icon | 1024x1024 PNG |
| App Icon (all sizes) | Auto-generated from 1024x1024 |

### Screenshot Guidance
Screenshots should show:
1. Card browsing/cast screen (main feature)
2. Card detail view
3. Search interface
4. Print preview (if printer is available)
5. Settings/printer setup screen

## Google Play (Android)

### Required Assets
| Asset | Specification |
|-------|---------------|
| App Icon | 512x512 PNG |
| Feature Graphic | 1024x500 PNG |
| Screenshots | Minimum 2, recommended 8 |

### Screenshot Requirements
- Phone screenshots: 16:9 or taller
- Tablet screenshots: 7"+ or 10"+ 

### Screenshots Guidance
Same as iOS — show the main app flows. Screenshots do NOT need to be from actual physical devices.

## Promotional Assets (optional)
| Asset | Specification |
|-------|---------------|
| App Store logo pack | Download from App Store Connect |
| Google Play store badge | From Play Store badges page |

## Asset Checklist
- [ ] 1024x1024 App Icon (iOS)
- [ ] 512x512 App Icon (Android)
- [ ] 1024x500 Feature Graphic (Android)
- [ ] iPhone 6.5" screenshots (min 1)
- [ ] iPhone 5.5" screenshots (min 1)
- [ ] Android phone screenshots (min 2)
- [ ] Privacy Policy URL hosted
- [ ] Support URL hosted

## Naming Convention
- iOS screenshots: `iphone-6.5-{number}.png`
- Android screenshots: `android-phone-{number}.png`
